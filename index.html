E81C 계산기

이미지를 올린 뒤 ①분석할 영역만 잘라내고 → ②눈금자 위에서 5mm 지점 → ③15mm 지점을 순서대로 클릭하면 두 지점 사이가 정확히 10mm라는 사실로 축척과 5–15mm 분석 구간이 한 번에 정해집니다. 이어서 ImageJ의 Otsu 자동 임계값 방식과 동일한 알고리즘으로 리튬 석출 면적률(%)을 구하고, E81C = (958 × 면적률) / 30656 공식에 바로 대입한 값을 보여줍니다.
